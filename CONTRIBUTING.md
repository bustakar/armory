# Contributing to Armory

Thanks for your interest in contributing!

## Getting Started

1. Clone the repository: `git clone https://github.com/bustakar/armory.git`
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Push and open a PR

## Development Setup

See [README.md](README.md) for setup instructions.

## Guidelines

- **Code Style**: Run `bun run lint` before committing
- **Commits**: Use clear, descriptive commit messages
- **PRs**: One feature/fix per PR, link related issues
- **Tests**: Add tests for new functionality when applicable

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes
3. Ensure linting passes
4. Open a PR with a clear description
5. Wait for review and approval

## Reporting Issues

- Check existing issues first
- Include steps to reproduce
- Add screenshots if relevant

## Questions?

Open a [Discussion](https://github.com/bustakar/armory/discussions) for questions.
